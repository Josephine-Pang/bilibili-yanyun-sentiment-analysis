# 游戏为媒，文化为魂：基于 B 站评论的《燕云十六声》文化传播效果研究

> 以国产开放世界游戏《燕云十六声》为案例，基于 B 站 **8,899 条视频评论**的情感分析与传播效果量化研究——比较官方账号与个人博主、四类传播主题在认知、情感、行为三个层面的文化传播效果差异。

## 项目背景

《燕云十六声》以河西走廊、敦煌文化为叙事底色，被视为"游戏载体传播传统文化"的代表性案例。本项目围绕以下研究问题展开：

1. **认知层面**：哪些传播主题（文脉传承 / 社会责任 / 科技赋能 / 地域活化）能引发更高的评论声量与互动？
2. **情感层面**：评论情感结构与"情感深度"（一般正面 → 赞美认同 → 情感共鸣 → 文化自豪）在各主题间如何分布？
3. **行为层面**：多少评论表达了明确的线下行为意向（旅游打卡、搜索学习、二次创作、自发传播）？
4. **主体对比**：官方账号与个人博主谁的传播效果更好？

## 核心发现

| 维度 | 结论 |
| --- | --- |
| 声量结构 | 文脉传承共振类视频贡献 74.8%（6,652 条）评论声量，是文化传播的核心载体 |
| 情感结构 | 正面 27.2%、中性 66.7%、负面 6.1%；深层情感（赞美/共鸣/自豪）361 条 |
| 主题差异 | 地域活化共振正面率最高（37.9%）、深层情感率 15.5%，"文旅体验"最能激发情感共鸣 |
| 行为意向 | 526 条评论含明确行为意向，其中"旅游意愿"占 71.5%（376 条）——游戏直接拉动线下文旅兴趣 |
| 主体对比 | 官方账号声量略高（4,521 vs 4,378 条）；个人博主在情感共鸣与行为意向激发上表现更优 |
| 互动特征 | 点赞与用户等级、评论长度显著正相关（Spearman），高等级用户是深度互动主力 |

## 技术栈

| 环节 | 工具 |
| --- | --- |
| 数据采集 | Python `requests`（B 站 wbi 签名接口、限速与游标分页、二级回复递归爬取） |
| 数据处理 | `pandas` / `openpyxl`；R `tidyverse` / `lubridate`（Rmd 分析流程） |
| 情感分析 | 情感得分（-1 ~ 1）+ 深度情感四分类 + 行为意向四分类标注体系 |
| 可视化 | `matplotlib`（渐变面积、雷达、热力图、气泡图、哑铃图、小提琴图等） |

## 数据说明

**脱敏声明**：所有发布数据均已删除 `用户ID / 用户名 / 个性签名 / 头像` 四类隐私字段，仅保留统计分析所需的匿名互动特征；处理逻辑见 `scripts/01_数据预处理_脱敏.py`。

**评论主数据集字段**（`data/processed/评论主数据集.csv`，8,899 行 × 21 列）：

| 字段 | 说明 |
| --- | --- |
| 评论内容 / 评论时间 / 点赞数 / 回复数 | 评论本体特征 |
| 用户等级 / 性别 / 是否是大会员 / IP属地 | 匿名用户画像 |
| BV号 / 视频名称 / 来源 / 账号类型 / 传播主题 | 视频与实验分组标注 |
| 情感得分 / 情感分类 / 深度情感分类 / 行为意向 | 情感与行为编码结果 |

## 快速开始

```bash
# 1. 安装依赖（Python >= 3.10）
pip install -r requirements.txt

# 2. 数据脱敏（原始数据更新时运行；输入目录 data/raw_source/）
python scripts/01_数据预处理_脱敏.py

# 3. 一键重绘全部论文图表 → figures/
python scripts/02_图表重绘.py
```

爬虫使用方法见 `scripts/crawler/bilibili_comment_crawler.py` 文件头注释（需先在脚本同目录放置 `bili_cookie.txt`）。
